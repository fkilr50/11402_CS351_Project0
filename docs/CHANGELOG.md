## [1.0.0] - 2026-03-26

### Added
- Initial project setup for CS351 Programming Assignment
- Two Sum algorithm implementation
- Main program entry point with basic functionality
- Complete documentation suite (API Reference, Architecture, Contributing guidelines)
- Google C++ Style Guide compliance
- Branch structure with main and test branches

### Project Structure
- `src/main.cpp` - Main program entry point
- `src/twosum.cpp` - Two Sum algorithm implementation
- Comprehensive documentation in `docs/` folder

### Features
- Efficient O(n) time complexity solution using hash map
- Support for finding two distinct numbers that sum to target
- Returns indices of the two numbers
